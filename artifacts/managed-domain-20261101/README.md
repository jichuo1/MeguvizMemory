# Java 托管域的开发证据

`host-dev.json` 记录独立宿主 JVM/JNI 开发检查：46 项受控故障/并发测试和 1 项无注入正常测试；测试 DLL 合并核心仅用于隔离检查，并非正式 Android 链接。失败隔离用例有意保留不确定资源，不计为正常归零。

`java-image-host.json` 记录使用安装后的共享核心和单独构建的 host JNI 的 Java 图像消费者。普通路径不加载身份诊断 sidecar；显式身份路径检查实际加载文件，但磁盘文件哈希不等于已映射内存哈希。Java 数组、初始化和 JNI 复制分开计数，不代表性能收益。

`android-build-only.json` 仅记录三 ABI 原始 JNI/AAR 的交叉构建和静态闭包；原始本地二进制含调试环境信息，**不可分享**。`android-sanitized/` 是独立脱敏候选的静态比较与 R8 build-only 证明；其中部分补充检查未保存完整脚本，不声称完整可复现构建或 ART 运行。当前没有新接口的 Android ART、设备、性能或正式发布资格。此前预览包不包含托管域，不能转授。
