# 继续开发的宿主证据

`host-dev-checks.json` 汇总 C++ checked 适配、宿主 JNI/JVM 与独立 Java 图像消费者的限定开发检查；`java-image-host.json` 保留图像对照、失败路径和加载身份的脱敏回执。宿主 JNI 是独立构建的运行库，不是 Android AAR 中的原生库；这些记录不构成设备、性能或正式发布资格。

`java-image-ci-host.json` 是随后新增可复跑宿主入口后的独立 Windows 构建和检查记录；它使用重新构建的宿主 JNI，不将上一轮原生二进制的结果转授。Linux 结果需要由该入口的 CI 实际执行确认。

`jni-close/receipt.json` 单独记录关闭锁循环的旧版失败、新版通过对照。该目录保存当时的旧 Java 源与同一测试源码的精确字节；中间修复版源码在该对照中仅记录了哈希，当前源码又增加了关闭状态观测，不把当前文件冒称为中间版本。原始日志和测试二进制仅留在忽略的本机构建目录。

上一份 `Feature-Preview-20261101.zip` 生成于这些后续源码改动之前，不包含本轮 Java 关闭修复、C++ checked 包装或新增 Java 图像消费者，不能将它称为当前源码的制品。
