# 后续工程候选证据

`windows/` 保存 Windows 候选和可选 Compute 桥的脱敏本机证明及相应测试源码。静态库比较、安装消费者及实际模块文件身份各有不同范围；隔离场景刻意保留不确定资源，并非正常资源归零。Windows ZIP 装配与补充路径扫描曾使用一次性命令，未保存完整独立脚本。

`android-borrow-v2/` 中无 `-final` 后缀的宿主和 R8 记录对应较早测试夹具，仅作历史保留；带 `-final` 的记录对应修正后的源码。宿主 62 项使用真实 JVM/JNI 和 Android 桩，并非 Android ART；R8 记录只证明构建和静态检查，离线 runner 记录不是真机执行。

`SOURCE_LOCK.json` 记录本轮源码观察快照，不单独证明可复现构建或制品来源；本地预览包哈希见本目录独立 `manifest.json`。当前仓库没有项目许可证文件，既有 LLVM notice 保留，正式发布资格尚未取得。
