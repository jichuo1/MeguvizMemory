# DEX 配对 reader 轨迹的受控字节回放

本工具先独立运行 [paired 采集](PAIRED_CONTRACT.md)，确认采集进程退出码为 0、唯一终态报告通过，并重新核对 v2 绑定中的 20 对 stdout/stderr 文件长度、摘要、输入和候选身份；随后在独立进程中按原顺序逐字节读取已记录的 `site / offset`。旧版或外部已有的采集回执不能单独作为本入口的回放资格，本入口不会接收现成 trace 来跳过采集。

每次运行先在新的 `build/` 输出目录独占写入输入快照；原始输入、快照、采集日志、轨迹、请求和回放结果均可能敏感，不应公开。`corrupt-input` 使用首字节置零后的实际输入及独立摘要；`invalid-lease` 与 `borrow-budget` 的零事件是合法拒绝路径，不生成伪造读取。事件必须来自完整、数量与范围校验通过的已绑定输出。父进程用输入快照独立计算 SHA-256，逐事件按 `site` 的 32 位小端、`offset` 的 64 位小端及读取的一个字节顺序更新；回放子进程独立读取其私有 backing 并计算同一摘要，逐对一致才继续。

若插桩采集按固定合同报告失败，配对采集器与本外层仅在约定退出码、脱敏 sidecar、终态及进度一致时传播 `INCOMPLETE` 的固定类别和有界计数；它标记为子进程自报，不能当作独立证实的根因，也不会产生回放成功回执。详细分类和饱和计数含义见[配对诊断合同](PAIRED_CONTRACT.md)。构造失败、分类缺失、输出错误后 stderr 不可用或其他异常仍只给通用 INCOMPLETE。此前生成的诊断程序和冻结计划不自动适用于新版，须重新准备、构建并另行冻结。

四种策略只模拟明确的本地 backing：`D-C0` 使用 64 字节对齐的普通私有副本；`D-Z0` 借用本进程已预载缓冲。前两者没有 Memory domain，只报告普通引用已清除，预载和 Python 缓冲开销不视为零复制或资源收益。`D-C1`/`D-C2` 分别使用 Memory System/Arena 域、32 MiB backing 预算和 64 字节对齐；写 lease 初始化后换读 lease，读取完成再释放 owner、请求关闭、归还 lease、collect/drain、验证 CLOSED 与账目归零并 destroy。Python 输入、事件列表、解释器及元数据不计入域预算。此流程是受控的单线程合成寿命，不重建采集时 Dex owner 回调、查询或跨线程释放。

任一原生调用异常或结果不符合预期时，可能已消费的句柄不重复释放或销毁，结果保守标为 UNKNOWN；外层遇到子进程非零、超时、输出超限或不完整报告均失败。只终止本工具启动的本地子进程，不能据此证明后代已退出或操作系统资源已回收。单独运行 worker 得到 `PASS_SCOPED_READER_BYTE_WORKER` 只表示其局部操作完成，不能证明采集绑定；只有外层 `paired_replay.py` 进程退出码为 0 且 `replay-receipt.json` 为 `PASS_BOUND_PAIRED_READER_REPLAY`，才构成限定通过证据。最终回执先独占写 pending 并 flush/fsync，再无覆盖原子发布并回读；即使出现完整文件，也必须同时核对最外层退出码。此过程不承诺断电后的目录持久性。

启动任何子进程前，外层将安装 SDK 全部文件与已识别候选归档比对，确认所选 core 是该安装前缀中的目标库；解释器使用 `-E -s -S` 和受限环境，不继承 Python/loader 注入或凭据，也不在解释器启动时加入 SDK 搜索路径。实际被测消费者仅在自身 SDK 核对后设置所需搜索路径。外层绑定输入、候选、core、采集/回放脚本、ABI 辅助脚本及请求的 Python 可执行文件的磁盘摘要，结束前再次检查；这些是本地一致性检查，不是签名来源、实际加载映像或映射字节证明。同权限进程可篡改本地文件，不能将回执当作防伪证明。

```text
python consumers/dex_trace/paired_replay.py --input <工作区原始DEX> --baseline <原样配对程序> --traced <插桩配对程序> --core <安装SDK共享核心> --candidate <候选归档> --candidate-evidence <候选摘要> --source-lock SOURCE_LOCK.json --dex-stage <隔离Dex准备目录> --paired-stage <隔离配对源码目录> --sdk-prefix <安装SDK前缀> --out-dir build/<全新回放目录>
```

源码准备和构建步骤见[配对诊断合同](PAIRED_CONTRACT.md)。`--max-events` 默认 250000、上限 1000000；每个子进程及外层均有时限和 stdout/stderr 内存上限。外层自身的身份摘要采用有上限的分块读取；配对采集子进程对部分其他文件的摘要是流式但没有单独字节上限，受其进程时限约束。总时限是协作式检查，不承诺中断一次文件扫描、单次系统调用或最终持久化。超限、截断、输入漂移、报告不一致和未知清理均不能输出成功回执。此工具无法独立证明采集事件覆盖所有解析访问，也不重放完整 DEX 查询、物理访问、TLB 或产品工作负载，更不证明性能收益；普通复制/借用与 Memory 增量仍须分开记账。
